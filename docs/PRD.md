# Product Requirements Document (PRD)
**Project Name:** IRCTC Tatkal Auto-Pilot Extension  
**Version:** 1.0  
**Date:** September 26, 2026  
**Status:** Draft  
**Target Launch:** MVP (v1.0)  

## 1. Product Overview
IRCTC Tatkal Auto-Pilot Extension is a high-performance browser extension designed to automate credential autofill, high-speed routing, and seamless Master List passenger injection for Indian Railways Tatkal bookings.

## 2. Problem Statement
Users struggle to secure confirmed Tatkal tickets due to extreme time constraints, manual typing latency, and multi-step UI navigation bottlenecks during the opening seconds of the booking rush.

## 3. Goals
* Provide a fast, automated form-filling and click-trigger mechanism for high-pressure booking windows.
* Eliminate manual typing latency at 10:00 AM / 11:00 AM.
* Maintain strict security and data privacy by storing credentials and configurations locally.

## 4. Target Users
* Frequent train commuters and regular travellers.
* Tech-savvy users looking for automated browser macros.

## 5. Core Features (MVP)
1. **Secure Local Configuration Panel:** Save route data, train numbers, class preferences, and encrypted IRCTC credentials locally.
2. **Automated Login Sequence:** Handle automated form injection for seamless session initiation.
3. **Millisecond Timer & Auto-Clicker:** Synchronize triggers to select class "Book Now" buttons and inject pre-configured passenger lists instantly.
