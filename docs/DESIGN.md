# Design System & UI Guidelines
**Project:** IRCTC Tatkal Auto-Pilot Extension — Clean, Simple, Productive.

## 1. Design Principles
* **User-Centered:** Simple and intuitive for high-stress, rapid-action configuration.
* **Minimal & Clean:** Clutter-free extension popup tailored for fast form updates.
* **Consistent:** Strict adherence to a uniform color palette and typography.

## 2. Color Palette
* **Primary (IRCTC Blue):** `#1B365D` (Main background accents, headers)
* **Secondary (Tatkal Gold):** `#F39C12` (Status highlights)
* **Success:** `#2ECC71` (Ready / Armed indicators)
* **Error:** `#E74C3C` (Missing fields or sync warnings)

## 3. Typography
* **Font Family:** Inter or system default sans-serif for optimal readability.
